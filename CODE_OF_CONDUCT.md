# Contributor Covenant Code of Conduct

## Our Pledge

We, as contributors and maintainers, pledge to foster a welcoming, inclusive, respectful, and harassment-free environment for everyone participating in the AgroTech community.

AgroTech is an open-source smart farming platform that combines IoT, web technologies, and mobile applications to improve crop monitoring, disease detection, and agricultural decision-making. We welcome contributors from all backgrounds who are passionate about agriculture, technology, IoT, artificial intelligence, and open-source collaboration.

## Our Standards

Examples of behavior that contribute to a positive community include:

- Treating everyone with respect, professionalism, and kindness.
- Providing constructive and respectful feedback.
- Collaborating openly and sharing knowledge.
- Supporting contributors of all experience levels.
- Writing clean, maintainable, and well-documented code.
- Respecting different viewpoints and technical approaches.
- Helping improve the project through meaningful discussions and contributions.

Examples of unacceptable behavior include:

- Harassment, discrimination, or hateful conduct.
- Personal attacks, intimidation, or abusive language.
- Publishing confidential or sensitive information without permission.
- Deliberately introducing malicious, insecure, or misleading code.
- Any behavior that creates a hostile or unwelcoming environment.

## Responsible Development

As AgroTech supports smart farming and agricultural monitoring, contributors are expected to:

- Follow secure coding practices.
- Protect user and farm-related data.
- Test IoT, web, and mobile features thoroughly before submitting changes.
- Clearly document significant changes and new functionality.
- Maintain high standards of code quality, reliability, and accessibility.

## Enforcement Responsibilities

Project maintainers are responsible for enforcing community standards and may take appropriate action when necessary.

## Scope

This Code of Conduct applies to all project spaces, including GitHub repositories, issues, pull requests, discussions, documentation, and official communication channels.

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers through the project's official communication channels.
